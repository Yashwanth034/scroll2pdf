# Scroll2PDF Privacy Policy

Effective date: September 23, 2026

Scroll2PDF is a Chrome/Chromium extension for capturing webpages, scrollable areas, selected regions, and visible screenshots and exporting them as images or PDF files.

## Data handled by Scroll2PDF

Scroll2PDF may process webpage content selected by the user, including text, images, and other visible page content. If the user chooses to capture a chat or conversation, that captured content may include personal communications.

Scroll2PDF only accesses this content when the user starts a capture.

## Local processing

All screenshot capture, stitching, image editing, PDF generation, preview, and temporary storage are performed locally in the user's browser.

Scroll2PDF does not upload captured webpage content to any external server.

## Data collection

Scroll2PDF does not collect:

- Personally identifiable information
- Health information
- Financial or payment information
- Authentication credentials
- Location information
- Browsing history
- Analytics or telemetry

## Data sharing

Scroll2PDF does not sell, transfer, or share user data with third parties.

User data is not used for advertising, profiling, creditworthiness, lending, or purposes unrelated to the extension's screenshot and PDF functionality.

## Temporary storage

Temporary capture results may be stored locally in the browser using IndexedDB while processing or displaying a capture. Temporary results are removed after use or expiration.

Downloaded images and PDF files are saved only when requested by the user.

## Permissions

Scroll2PDF uses the following Chrome permissions:

- `activeTab` — accesses the webpage selected by the user for capture.
- `scripting` — runs locally bundled capture and selection code on the selected webpage.
- `offscreen` — performs screenshot stitching, image processing, and PDF generation.
- HTTP/HTTPS host access — allows Scroll2PDF to capture ordinary webpages selected by the user.

These permissions are used only to provide the extension's capture functionality.

## Remote code

Scroll2PDF does not execute remotely hosted JavaScript or WebAssembly code.

## Changes to this policy

This privacy policy may be updated if Scroll2PDF's functionality or data-handling practices change.
