# Scroll2PDF

Capture beyond the screen. Scroll2PDF turns full webpages, scrollable panels, chats, and selected regions into readable long images or clean A4 PDFs.

Highlights:

- Full Page, Scrollable Area, and Selected Area capture.
- PNG High quality or readable Standard JPEG.
- Portrait and Landscape A4 PDF output.
- Difficult-page support for dynamically loaded and virtualized chat views.
- Best-effort structural adapters for WhatsApp Web and Telegram Web.
- Progress, cancellation, restoration, and a responsive result preview.

All processing happens locally in the browser. Scroll2PDF does not upload screenshots, message text, credentials, cookies, or analytics data. It does not call private site APIs or switch conversations.

Support is best effort for changing web applications. Cross-origin iframes, hidden application stores, and recursive multi-container capture are not supported.
